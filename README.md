# 🚀 LaunchPad

A full-stack student collaboration platform that helps students discover projects, build teams, collaborate in real time, and manage project workflows.

[Hero Screenshot]

## ✨ Features

🔐 Authentication
- JWT Authentication
- Refresh Token Rotation
- Secure Session Management

👤 User Profiles
- Public Profiles
- Skills
- Interests
- Portfolio Links

📂 Project Marketplace
- Create Projects
- Search
- Filters
- Bookmarks

👥 Team Formation
- Join Requests
- Accept / Reject
- Team Management

💬 Real-time Collaboration
- Team Chat
- Online Presence
- Notifications

📋 Task Management
- Kanban Board
- Drag & Drop
- Task Assignment
- Activity Timeline

🎨 Modern UI
- Minimal SaaS Design
- Responsive
- Tailwind CSS
